# AsistentIno

Simple assistant for Arduino projects and related tooling.

## Description
AsistentIno is a small .NET 10 application that helps with Arduino development workflows. It provides project utilities and integrations used during development. This project was created for educational purposes and is not intended for commercial use.

## Requirements
- .NET 10 SDK
- Visual Studio 2026 or any compatible IDE

## Build & Run
1. Open the solution (AsistentIno.sln) in Visual Studio, or use the command line.
2. From the repository root:
   - dotnet build
   - dotnet run --project AsistentIno
