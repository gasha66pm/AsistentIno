# AsistentIno

Simple assistant for Arduino projects and related tooling.

## Description
AsistentIno is a small .NET 10 application that helps with Arduino development workflows. It includes small utilities and AI-assisted helpers for working with Arduino projects, such as code suggestions and device interaction helpers. This project was created for educational purposes and is not intended for commercial use.

## Requirements
- .NET 10 SDK
- Visual Studio 2026 or any compatible IDE

## Build & Run
1. Open the solution (AsistentIno.sln) in Visual Studio, or use the command line.
2. From the repository root:
   - dotnet build
   - dotnet run --project AsistentIno

# AsistentIno

Jednostavan asistent za Arduino projekte i povezane alate.

## Opis
AsistentIno je mala .NET 10 aplikacija koja pomaže u radu na Arduino projektima. Sadrži male alate i AI-pomoć za rad na Arduino projektima, kao što su predlozi koda i pomoć pri komunikaciji sa uređajima. Projekat je napravljen u edukativne svrhe i nije namenjen za komercijalnu upotrebu.

## Zahtevi
- .NET 10 SDK
- Visual Studio 2026 ili neki kompatibilan IDE
